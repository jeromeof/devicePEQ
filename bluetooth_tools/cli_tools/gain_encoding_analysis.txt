Hex: AA EC 44 00 06 A5 A5 A5 C1 AD AF EC

================================================================================
GAIN ENCODING FORMULA:
================================================================================

Delta: 173 - 169 = 4
**4 counts per dB**

Formula:
gain_byte = 169 + (gain_dB * 4)
gain_byte = 0xA9 + (gain_dB * 4)

Examples:
- 0dB:   169 + (0 * 4)  = 169 (0xA9) ✓
- +1dB:  169 + (1 * 4)  = 173 (0xAD) ✓ VERIFIED
- +3dB:  169 + (3 * 4)  = 181 (0xB5)
- +6dB:  169 + (6 * 4)  = 193 (0xC1)
- -3dB:  169 + (-3 * 4) = 157 (0x9D)
- -6dB:  169 + (-6 * 4) = 145 (0x91)

================================================================================
SET_BAND PAYLOAD STRUCTURE (6 bytes):
================================================================================

Byte 0: Band Index (A5=filter 0, A4=filter 1, A7=filter 2, etc.)
Byte 1: Unknown (always A5=165?)
Byte 2: Unknown parameter
Byte 3: Frequency parameter (needs more analysis)
Byte 4: GAIN (0xA9 + gain_dB * 4)
Byte 5: Terminator (always 0xAF)
